# Privacy Policy

Power Plan Tray does not collect, store, or transmit personal data, usage data, diagnostics, or telemetry. It has no accounts, advertising, analytics, or background network service, and it does not require an internet connection. The Privacy Policy and Terms buttons only ask Windows to open their public GitHub pages in your default browser.

Preferences and automation rules are stored locally in the app's Windows application-data folder. Exported advanced-setting profiles are written only to a file you choose.

The app normally runs without administrator privileges. Windows may show a User Account Control prompt for a narrowly scoped `powercfg` helper operation when you create or remove standard power plans or change the visibility of advanced power settings. Only that helper operation is elevated; the app itself is not restarted or kept running as administrator.

Power Plan Tray reads and changes local Windows power-plan settings solely to provide the features you request. It does not send those settings anywhere.

If this policy changes, the updated policy will be published in this repository.
